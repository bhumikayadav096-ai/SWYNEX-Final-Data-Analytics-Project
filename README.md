 India Rainfall Analytics Dashboard

 1. Problem Statement
 The objective of this project is to analyze historical rainfall data across India to identify seasonal, yearly, and regional rainfall patterns and develop an interactive dashboard for intuitive data exploration.

 2. Dataset Information
 Datasets Used: Rainfall in India (1901–2015) & District-wise rainfall normal dataset
 Time Period: 115 years of historical data
 Coverage: 36 meteorological subdivisions across India

 3. Data Cleaning & Preparation
 Checked and handled missing or invalid values.
 Removed duplicate records to ensure data accuracy.
 Corrected data types for proper analysis.
 Created a dedicated 'Month' table and sorted months chronologically (Jan–Dec).
 Applied various data transformations using Power Query.

 4. Data Analysis
 Year-wise Trends: Analyzed long-term rainfall fluctuations.
 Month-wise Rainfall: Evaluated seasonal changes and monsoon impacts.
 Rainfall Normal Comparison: Compared actual rainfall against expected normal rainfall.
 Subdivision/Region Analysis: Mapped geographical disparities in rainfall distribution.

 5. Dashboard Features
 KPI Cards: Displaying high-level metrics at a glance.
 Yearly Trend Line Chart: Tracking historical rainfall over the decades.
 Monthly Analysis Bar Charts: Highlighting peak rainfall months.
 Interactive Slicers & Filters: Filter data dynamically by Subdivision, State, and District.

 6. Key Insights
 Extensive Data Coverage: The dataset successfully models 115 years of historical observations across 36 subdivisions.
 Monsoon Peak: The months of July and August record comparatively high rainfall, with July's average rainfall normal around 400.88 mm.
 Regional Variations: Regional rainfall patterns vary significantly according to the subdivisions.
 Analytical Value: The dashboard helps users explore historical rainfall patterns across years, months, and regions, which can support further planning and analysis related to agriculture, water resources, and climate-sensitive activities.
